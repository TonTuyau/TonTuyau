# TonTuyau 1.2.0 (in progress)

Not released yet. First step: **logging in**.

- A PostgreSQL (`tontuyau-db`, `postgres:17`) holds the accounts; the first start creates the admin from `TONTUYAU_ADMIN_USER` / `TONTUYAU_ADMIN_PASSWORD`.
- Passwords as OWASP recommends: Argon2id, 19 MiB, 2 passes, 1 lane, a salt each, PHC strings.
- `/login` (EN / FR), "Log in" in the top bar, the name's initial and Log out once logged in. Browsing still needs no login; no admin pages yet.
- Upgrading from 1.1: add `TONTUYAU_DB_PASSWORD` and `TONTUYAU_ADMIN_PASSWORD` to `.env` (see `.env.example`), then `docker compose up -d`.
- Login attempts: 5 a minute per visitor's address. Behind your HTTPS reverse proxy, name it in `TONTUYAU_TRUSTED_PROXIES` (its address as the front server sees it) so each visitor gets their own attempts; only the proxy's `X-Forwarded-For` entry is trusted.
- Kept as they are (your answers): usernames are case-sensitive; no minimum length for the admin's password; logging out deletes the cookie in the browser (a serious account management would come with an identity provider such as Authentik).
