# TonTuyau 1.2.1

A fix to [1.2.0](1.2.0.md)'s admin dashboard.

- **Import history, last day: a bar for every sync.** The last day showed only the syncs that brought new videos: on the deployed library, five bars side by side, which didn't read as 24 hours. Now every sync of the last 24 hours has its bar, an empty one for a sync that found nothing new (still none for an index rebuild or a sync still running); the hover shows each sync's time and counts. The other periods are unchanged.

## Upgrading

Pull the new images (`docker compose pull && docker compose up -d`): no configuration, database or index change.
