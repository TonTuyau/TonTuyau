# TonTuyau 1.2.2

An option on [1.2.0](1.2.0.md)'s admin dashboard.

- **Import history: a linear or log scale.** A switch beside the periods draws the chart on a linear scale (as before, the default) or a logarithmic one, so one big import (a new channel's backlog) no longer flattens the others into slivers. The log axis is log10(1 + n): 0 stays on the baseline and a single video still has a bar; it reads 0, 1, 10, 100… up to the top. Each bar is as tall as its total, and its types share that height by their counts; the hover gives the exact numbers either way. The choice is remembered in the browser, like the period.

## Upgrading

Pull the new images (`docker compose pull && docker compose up -d`): no configuration, database or index change.
